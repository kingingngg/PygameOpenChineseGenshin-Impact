# PygameOpenChineseGenshin-Impact | 用Pygame打开原神
Use Pygame to open the Chinese version of Genshin Impact, but this is not a game.It's just homework!  
使用Pygame打开一个假原神，他不是真正的游戏，你可以理解成这是一次作业！

## What is this? | 这是什么
"Chinese Genshin Launcher" made with Python and Pygame. It plays Genshin Impact's launch screen and the "launch tune" popular on the Chinese internet. Therefore, it is essentially a media player — you can think of it as a product of the Chinese internet culture.<dr>
基于Python和Pygame制作的“原神启动器”，它会播放原神的启动界面，播放启动小曲，换句话说它本身就是一个播放器，你可以理解成玩梗。

## How to run? | 怎么运行
1. Make sure Python (3.11.9+, tested with 3.11.9) and Pygame (2.6.1+, tested with 2.6.1) are installed;
确保安装了 Python (3.11.9+，测试环境使用3.11.9）、Pygame (2.6.1+，测试环境使用2.6.1);

2. Download the entire project completely;
完整下载整个项目；

3. Run code/main.py.
运行 code/main.py 。
